# Мост датчиков window.FSNative

Мост добавляется в WebView через `addJavascriptInterface(bridge, "FSNative")`. Все методы синхронные и возвращают строку. Страница разбирает строку через `JSON.parse`. Наличие `window.FSNative` определяет нативный режим: страница включает «Реал» по умолчанию и использует мост вместо датчиков браузера.

## Методы

### `start()` → JSON

Запускает сбор. Перед запуском проверяются разрешение геолокации и системная служба. Накопители сбрасываются, счётчик шагов обнуляется (первый срез даст `steps = null`).

Успех: `{"ok":true}`.

Отказ: `{"ok":false,"error":"LOCATION_PERMISSION_MISSING"}` либо `{"ok":false,"error":"LOCATION_SERVICE_DISABLED"}`. Страница не создаёт сессию и показывает код.

### `stop()` → `"ok"`

Снимает подписки на позицию, датчики и распознавание активности.

### `sample()` → JSON

Срез за прошедший тик. Вызывается страницей раз в секунду. Накопитель IMU и база шагов сбрасываются при каждом вызове.

| Поле | Тип | Смысл |
| --- | --- | --- |
| `fix` | объект или `null` | Последняя позиция fused location. Один и тот же фикс может повторяться в нескольких срезах: `id` не меняется |
| `fix.id` | число | Порядковый номер фикса с момента `start()` |
| `fix.lat`, `fix.lon` | число | Координаты, градусы |
| `fix.acc` | число | Горизонтальная точность, метры. Нет значения: `9999` |
| `fix.speed` | число или `null` | Скорость ОС, м/с |
| `fix.sacc` | число или `null` | Точность скорости, м/с |
| `fix.ts` | число | Календарное время фикса, мс UTC |
| `fix.age` | число | Возраст фикса на момент среза, секунды, по монотонным меткам |
| `fix.mock` | логический | Признак подменного поставщика |
| `steps` | число или `null` | Шаги за тик (разность накопленного счётчика). `null`: первый срез, нет значения счётчика, откат счётчика, нет датчика |
| `sma` | число или `null` | Среднее `abs(ax)+abs(ay)+abs(az)` по линейному ускорению за тик. `null`: нет отсчётов |
| `imuN` | число | Число отсчётов IMU за тик |
| `act` | объект или `null` | Последнее наблюдение активности. `null`: наблюдений ещё не было |
| `act.code` | строка | `WALKING`, `RUNNING`, `STILL`, `VEHICLE`, `UNKNOWN` |
| `act.conf` | число | Уверенность, 0–100 |
| `act.age` | число | Возраст наблюдения, секунды |

### `caps()` → JSON

Состояние источников для панели диагностики: `locationPerm`, `gpsEnabled`, `fixing`, `accel`, `imuN` (всего с момента старта), `stepPerm`, `stepCounter`, `stepDetector` (всегда `false`), `actPerm`, `actAvail`, `actCode`, `actAge`.

### `requestPermissions()`

Повторно показывает системный запрос разрешений.

### `saveFile(name, mime, text)` → строка

Сохраняет текст в каталог «Загрузки». Возвращает `"ok"` либо текст ошибки. Недопустимые символы имени заменяются на `_`.

## Приведение к RawTick

Страница строит из среза поля слоя 3:

| Поле RawTick | Источник |
| --- | --- |
| `has_fix` | `fix` не `null`, `fix.acc` не больше `UI_ACC_THRESHOLD`, `fix.age` не больше `GNSS_FRESHNESS_MAX_SEC` |
| `speed_os_mps` | `fix.speed` |
| `imu_buffer_ok` | `imuN` не меньше `IMU_MIN_SAMPLES_PER_TICK` |
| `steps_delta` | `steps` (`null` отключает проверки шагов на этом тике) |
| `activity_code`, `activity_age_sec`, `activity_confidence` | `act.code`, `act.age`, `act.conf` |
| `mock_location` | `fix.mock` |
